# Catálogo de trilhas — sugestão na entrega (Fase 6)

Biblioteca de fundo phonk da Vhoe, para a skill sugerir uma trilha que combine com o reel pronto.

**Pasta-raiz das trilhas** (fonte de verdade): resolva nesta ordem, a variável de ambiente `VHOE_MUSICAS` ou o campo `musicas_dir` de `config.local.json` (na pasta desta skill; arquivo ignorado pelo git). Sem nenhum dos dois, pergunte o caminho ao usuário. No setup do autor aponta para a pasta `Músicas/` do projeto no Drive de trabalho.

Duas camadas:
- **`Músicas/` (raiz)** → faixas de YouTube = **com copyright** (risco de Content ID). Uso só **orgânico**, de preferência aplicando pela **biblioteca de áudio do próprio Instagram** (busca pelo nome no app). NÃO usar em anúncio pago.
- **`Músicas/No-Copyright (Pixabay - livre pra ads)/`** → **sem copyright** (licença Pixabay). Seguras para qualquer uso, **inclusive anúncio pago**. Prefixo de arquivo: `Pixabay - `.

## Receita da sugestão (o que produzir)

Sugira **exatamente 2 faixas com copyright + 2 sem copyright**, do mesmo balde do reel, em **ordem de prioridade** (a #1 de cada lista é a que mais combina). Para cada faixa, uma frase ligando ao vídeo. Se o balde tiver < 2 opções, complete com o balde adjacente mais próximo e diga isso. Loops curtos (~44–46s): só sugerir para reels de até ~15s ou avisando que repete.
